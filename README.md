# Radar Contábil — PJ CONTABILIDADE LTDA

Portal responsivo com notícias e conteúdos informativos sobre contabilidade, tributos, gestão empresarial e tecnologia.

## Estrutura
- `index.html`: conteúdo e estrutura da página
- `css/styles.css`: estilos, layout responsivo e identidade visual
- `js/main.js`: menu mobile, data dinâmica e filtros por categoria
- `assets/`: diretório reservado para imagens locais

## Como visualizar
1. Extraia o arquivo ZIP.
2. Abra `index.html` em um navegador moderno.
3. Para publicar, envie os arquivos mantendo a estrutura de pastas para sua hospedagem.

## Observações
- O portal utiliza textos editoriais informativos de exemplo; não são notícias em tempo real nem substituem orientação contábil individual.
- Antes de publicar notícias com datas, alíquotas, prazos ou alterações legais, revise os dados e inclua fontes oficiais atualizadas.
- A fonte tipográfica é carregada do Google Fonts quando há conexão com a internet; o site continua funcional sem ela.
