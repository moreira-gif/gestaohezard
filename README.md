# PJ Contabilidade — site institucional

## Estrutura do projeto

```text
PJ_Contabilidade_Organizado/
├── index.html              # Página principal do site
├── noticias.html           # Página de notícias contábeis
├── assets/
│   ├── css/
│   │   └── style.css       # Estilos do site e da página de notícias
│   └── js/
│       └── main.js         # Menu responsivo e ano automático
└── docs/
    └── GUIA.md             # Orientações para edição e publicação
```

## Como visualizar

1. Extraia o ZIP mantendo a estrutura das pastas.
2. Abra `index.html` em um navegador.
3. Use o link **Notícias** no menu para abrir `noticias.html`.

## Publicação

Envie todos os arquivos para uma hospedagem de site estático, preservando a estrutura de diretórios. O `index.html` fica na raiz para facilitar a publicação.

## Antes de publicar

- Telefone e e-mail não foram informados e, por isso, não foram inventados.
- Confirme os dados cadastrais e os serviços com a empresa.
- A identidade visual é uma proposta de design, não uma afirmação de marca registrada.
- A página de notícias resume publicações externas e aponta para as fontes originais. Confira as fontes antes de tomar decisões contábeis ou fiscais.
- As fontes do Google Fonts precisam de internet; o site permanece utilizável sem elas.
