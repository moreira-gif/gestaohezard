PJ CONTABILIDADE — SITE INSTITUCIONAL
=====================================

ARQUIVOS
- index.html: estrutura e conteúdo do site.
- assets/style.css: identidade visual e layout responsivo.
- assets/script.js: menu mobile e ano automático no rodapé.

COMO ABRIR
1. Extraia o arquivo ZIP.
2. Abra a pasta pj_contabilidade_site.
3. Clique duas vezes em index.html para visualizar no navegador.

PUBLICAÇÃO
Você pode publicar esta pasta em serviços de hospedagem estática, como Netlify, Vercel ou GitHub Pages. Envie todos os arquivos mantendo a pasta assets.

IMPORTANTE ANTES DE PUBLICAR
- O telefone e o e-mail não constavam nos dados fornecidos. O site não inventa esses dados e indica que os canais oficiais devem ser confirmados.
- Confirme com a empresa os serviços descritos e as informações cadastrais antes de colocar o site no ar.
- A identidade visual é uma proposta institucional criada para este projeto; não implica que seja a marca oficial já utilizada pela empresa.
- O botão “Ver localização no mapa” abre uma busca de endereço no Google Maps.
- As fontes do Google Fonts precisam de internet para carregar; o site continua funcional sem elas.
